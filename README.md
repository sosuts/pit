# Pit - A Python Git Implementation

[![Pytest in uv venv](https://github.com/sosuts/pit/actions/workflows/pytest.yaml/badge.svg)](https://github.com/sosuts/pit/actions/workflows/pytest.yaml)

WARNING:  
This project is just getting started. The minimum required implementations are not yet in place.

Pit is a re-implementation of Git in Python for educational purposes. It is not intended for production use.
